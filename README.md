# SongLumen

A lightweight macOS menu-bar app that shows a quick, artwork-aware card when the Apple Music track changes.

## Status

Work in progress. The current build is signed for local distribution; an App Store-compatible sandboxed architecture is planned next.

## Build

Run `zsh build.sh`. The signed app bundle is written to `../../outputs/SongLumen.app` when a matching Developer ID certificate is available.
